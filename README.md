# SICU 班表轉行事曆

## 啟動
```bash
npm install
npm run dev
```
手機測試時，讓 iPhone 與電腦連同一個 Wi-Fi，開啟終端機顯示的 Network 網址。

## 目前暫定規則
- D 08:00–16:00
- E 16:00–00:00（跨日）
- N 00:00–08:00
- C 08:00–17:00
- 休假代碼預設不匯出
- D新/E新 解析為 D/E 加「新」註記
- #、/ 保留為註記

## 注意
PDF 表格解析使用文字座標與列位置。不同月份若版型改變，可能需要調整 `src/services/parser.ts`。匯入前請逐日確認。
